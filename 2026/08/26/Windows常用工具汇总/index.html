Windows常用工具-kikock

kikock2026-08-262026-08-26

Windows常用工具

工具列表：ShareX、BCUninstaller、mise、Netcatty、DBX、LeePanel、NetSetMan

平台标记：✅支持Windows ｜🍎支持macOS ｜🐧支持Linux

1. ShareX｜截图录屏OCR工具

简介：开源免费截图工具，支持区域截图、滚动长截图、OCR文字识别、录屏GIF/MP4、贴图悬浮。

支持平台：✅Windows

官网：https://getsharex.com/

Github：https://github.com/ShareX/ShareX

下载地址：https://getsharex.com/downloads

核心功能

  1. 区域/全屏/活动窗口截图
  2. 滚动长截图，捕获超长网页窗口
  3. OCR图片文字识别，直接复制文本
  4. MP4/GIF屏幕录制
  5. 截图自动保存本地，支持图床上传
  6. 贴图功能，截图悬浮屏幕

默认快捷键

  • PrintScreen：区域截图
  • Shift+PrintScreen：滚动截图
  • Ctrl+Shift+PrintScreen：OCR识别

💡提示：设置内关闭自动上传，防止隐私图片误上传；自定义截图保存路径。

2. BCUninstaller｜强力软件卸载清理

简介：开源免费卸载工具，卸载软件后扫描残留文件、注册表；支持商店应用、强制卸载顽固程序。

支持平台：✅Windows

Github：https://github.com/Klocman/Bulk-Crap-Uninstaller

下载地址：https://github.com/Klocman/Bulk-Crap-Uninstaller/releases

核心功能

  1. 批量卸载多个软件
  2. 卸载完成自动扫描残留文件夹、注册表
  3. 支持微软Store应用卸载
  4. 强制卸载无法正常移除的软件
  5. 过滤系统组件、隐藏程序

⚠️注意：不要随意勾选未知系统组件，防止误删系统文件。

使用流程

  1. 等待读取全部软件列表
  2. 勾选目标软件，执行卸载
  3. 等待程序自带卸载完成，执行残留扫描
  4. 确认后删除残留文件与注册表项

3. mise｜多语言版本管理器

简介：跨平台工具，统一管理 Node / Python / Java / Go / Rust 等多版本环境，替代 nvm、pyenv、sdkman。

支持平台：✅Windows ｜🍎macOS ｜🐧Linux

Github：https://github.com/jdx/mise

官网：https://mise.jdx.dev/

下载地址：https://mise.jdx.dev/getting-started.html

常用命令

# 查看远程可安装版本
mise ls-remote node
# 安装指定版本
mise install node@22
# 设置全局默认版本
mise global node@22
# 当前shell临时切换版本
mise use node@20
# 当前项目锁定版本，写入.mise.toml
mise use --local python@3.11
# 查看本地已安装环境
mise ls

💡Windows 提示：PowerShell 执行 mise activate，配置 shims 环境变量，否则版本不生效。

4. Netcatty｜跨平台终端与 AI 运维工具

简介：开源跨平台终端工作区与 SSH/SFTP 客户端，集成 AI 运维助手（Catty Agent），支持多标签会话管理与命令智能生成。

支持平台：✅Windows ｜🍎macOS ｜🐧Linux

Github：https://github.com/binaricat/Netcatty

下载地址：https://github.com/binaricat/Netcatty/releases

核心功能

  1. 支持 SSH、SFTP 及 Serial 串口连接与文件可视化传输管理
  2. 内置 Catty Agent AI 运维助手，支持自然语言生成命令与排错分析
  3. 多终端工作区与标签页管理，支持语法高亮与多主题切换
  4. 会话配置云同步与快速连接管理

使用说明

  1. 新建 SSH / 串口连接或本地终端会话
  2. 可通过右侧 SFTP 侧边栏进行文件上传与下载管理
  3. 开启内置 AI 助手辅助执行运维命令或排查错误

5. DBX｜轻量多数据库客户端

简介：开源轻量跨平台数据库 GUI 工具，Tauri+Rust 开发，体积仅约 15‑20MB，内置 AI SQL 助手，支持60+种数据库，无需 Java 运行时，无捆绑依赖。

支持平台：✅Windows ｜🍎macOS ｜🐧Linux

Github：https://github.com/t8y2/dbx

发布页：https://github.com/t8y2/dbx/releases

指定版本下载：https://github.com/t8y2/dbx/releases/tag/v0.5.95

官网：https://dbxio.com/cn

核心功能

  1. 全品类数据库支持：MySQL、PostgreSQL、SQLServer、Oracle、SQLite、Redis、MongoDB、达梦、金仓、TDengine 等60+数据库，兼容国产数据库与主流开源/商业数据库
  2. 专业SQL编辑器：语法高亮、智能补全、SQL格式化、选中执行、操作历史记录、多主题切换
  3. 可视化数据管理：表格数据预览、筛选、行内编辑，支持导出 CSV/XLSX/JSON/Markdown 等格式
  4. 结构管理工具：表结构编辑、ER图可视化、跨库Schema对比、查询执行计划分析
  5. AI SQL助手：支持自然语言生成SQL、SQL优化、错误修复，适配OpenAI、Claude、Ollama本地大模型
  6. 高阶能力：支持MCP协议对接AI编程工具、Docker自托管部署、SSH隧道连接、离线驱动安装

💡提示：Windows直接下载exe安装包，全程无冗余依赖，轻量化启动，支持离线使用。

6. LeePanel｜无 Agent 跨平台 Linux 服务器管理面板

简介：基于 Tauri 2 + React 开发的开源跨平台 Linux 服务器 / VPS 控制面板，无服务端代码注入与端口暴露风险，纯通过本地 SSH 协议远程管理服务器。

支持平台：✅Windows ｜🍎macOS ｜🐧Linux

Github：https://github.com/gna1280072/LeePanel

下载地址：https://github.com/gna1280072/LeePanel/releases

核心功能

  1. 零服务端残留：桌面端直接通过 SSH 通信，无需在服务器安装面板程序或开放 8888 等高危端口
  2. SSH 终端与 SFTP 文件管理：支持可视化文件拖拽上传/下载、解压缩及权限修改
  3. LNMP / 软件栈运维：一键管理 Nginx 站点、MySQL/MariaDB 数据库、PHP 多版本切换及 Redis
  4. Docker 容器管理：镜像拉取、容器生命周期管理及日志查看
  5. 防火墙与 Let’s Encrypt SSL：可视化规则配置及证书一键申请部署

💡技巧：在本地桌面配置好服务器 SSH 密钥后，即可直接添加多台服务器进行可视化运维，零侵入无残留。

7. NetSetMan｜网络配置一键切换

简介：Windows 专用网络配置切换工具，支持多套IP、子网、网关、DNS、Hosts一键切换，适配办公、内网、家庭多场景网络切换需求。

支持平台：✅Windows

官网：https://www.netsetman.com/

下载地址：https://www.netsetman.com/en/download

核心功能

  1. 自定义保存多套网卡网络配置档案，一键切换
  2. 快速修改IP地址、子网掩码、网关、DNS服务器
  3. 支持批量修改Hosts文件、计算机名、工作组
  4. 支持网卡启用/禁用、WiFi配置管理、网络状态查看

⚠️必须以管理员权限运行，否则修改IP、Hosts会出现权限报错，配置无法生效。

使用步骤

  1. 新建自定义配置集，填写对应IP、子网、DNS等网络参数
  2. 选择当前使用的有线/Wi‑Fi网卡，绑定配置
  3. 保存配置，后续切换网络场景直接点击激活即可
