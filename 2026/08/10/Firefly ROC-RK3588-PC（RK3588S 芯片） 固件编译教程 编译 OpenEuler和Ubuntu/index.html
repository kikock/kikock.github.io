⚠️ 重要前置说明（离线部署原则）

GitHub 境外域名在内网环境无法访问，全程禁止在线拉取源码。
本文档离线章节全部采用纯离线部署方案：提前在外网设备下载所有资源后上传编译机，镜像内本地安装，不依赖任何外网连接。

第一章 SDK 获取

请联系销售（sales@t-firefly.com）获取 SDK 下载链接，并阅读下载链接的 readme 文档。

注意事项：

  1. SDK 采用交叉编译，须在 X86_64 电脑上使用 SDK，不要将 SDK 下载到板子上
  2. 编译环境请使用 Ubuntu 20.04（真机或 Docker 容器），使用其他版本可能导致编译出错
  3. 不要在虚拟机共享文件夹以及非英文目录存放、解压 SDK
  4. 获取、编译 SDK 请全程使用普通用户，不允许也不需要使用 root 权限（除非需要 apt 安装软件）

离线环境补充：如果无法访问外网，请参考本文档第六章：离线环境特殊操作。

3.3 分区说明

parameter 文件中包含了固件的分区信息，例如 device/rockchip/rk3588/parameter-xxxxxx-fit.txt：

分区解读（以 uboot 为例）：

0x00002000@0x00004000(uboot) 中：

  • 0x00004000 = uboot 分区起始位置
  • 0x00002000 = uboot 分区大小（单位：块，每块 512 字节）

计算：0x00002000 = 8192 块 = 8192 × 512 / 1024 / 1024 = 4 MiB

分区名 镜像文件 说明
uboot uboot.img U-Boot 引导加载器
misc misc.img 引导控制分区
boot boot.img / extboot.img 内核 + 设备树
recovery recovery.img 恢复分区
backup — 备份分区
rootfs rootfs.img 根文件系统（系统主体）
userdata — 用户数据分区（自动扩展）

# 规则
1 rootfs 结构性修改后，必须全量编译（./build.sh all），否则必卡 Logo
2 system/ 目录缺失，install_system.sh 会联网（内网必失败）
3 OpenEuler 镜像内默认无 /usr/local/bin，chroot 前须 mkdir -p
4 离线环境 repo sync 必须加 -l 参数（本地模式）
5 卸载镜像前必须 sync，防止数据未写入导致镜像损坏
6 SDK 编译必须在 x86_64 宿主机上进行，不能在板子上编译
7 编译全程使用普通用户，不用 root（apt 安装除外）
